# 🧠 놀이 원리 14가지: 아이는 왜 이걸 좋아할까?

엄마표 놀이 대부분은 아래 원리 몇 개를 **생활 물건**으로 조합한 거예요.
원리를 알면 집에 있는 물건만 보고도 새 놀이를 만들 수 있어요.

## 아이가 빠지는 놀이의 5가지 조건
1. **결과가 바로 보여요.** 누르면 소리 나고, 넣으면 사라지고, 치면 무너져요.
2. **몇 번이고 다시 할 수 있어요.** 끝나도 "또!"가 바로 돼요.
3. **조금 어렵지만 할 만해요.** 살짝 힘을 줘야 빠지고, 겨우 닿는 정도예요.
4. **진짜 어른 물건이에요.** 장난감보다 국자, 냄비, 빨래집게를 더 좋아해요.
5. **아이 몸에 맞는 작은 세상이에요.** 상자, 이불 텐트, 식탁 아래처럼요.

## 원리 목록
`principles` 칸에는 아래 이름 그대로 써요.

|---|---|---|---|
| **넣고빼기** | "들어가면 어디로 가지?" 안과 밖을 알아 가요 | 7개월~ | 통·상자·지퍼백·빨래 바구니·티슈 상자 |
| **옮기기** | 여기서 저기로 나르는 것 자체가 재밌어요 | 12개월~ | 국자·계량컵·숟가락·바구니·장바구니 |
| **숨기고찾기** | 안 보여도 있다는 걸 알게 돼요 (대상영속성) | 6개월~ | 손수건·컵·이불·종이봉투 |
| **원인결과** | "내가 하니까 변했다!" 하는 힘을 느껴요 | 4개월~ | 스위치·뽁뽁이·스펀지 짜기·풍선 |
| **굴리고던지기** | 날아가고 굴러가는 길(궤적)이 신기해요 | 9개월~ | 휴지심·페트병·양말 공·빨래 바구니 |

| **분류짝맞추기** | 같은 것끼리 모으며 세상을 정리해요 | 18개월~ | 양말·신발·뚜껑·머핀틀·빨래 |

| **몸으로도전** | 기어오르고, 넘고, 균형 잡는 게 짜릿해요 | 7개월~ | 베개·쿠션·이불·마스킹테이프 선 |

## 새 놀이 만드는 공식
**원리 1~2개 + 집에 있는 물건 1~2개 + 아이 나이에 맞는 난이도**

- 예) 꽂고잇기 + 채반 → 채반 구멍에 빨대 꽂기
- 예) 당기고떼기 + 빨래집게 + 상자 → 상자 테두리 빨래집게 떼기
- 예) 굴리고던지기 + 휴지심 + 벽 → 벽에 휴지심 미끄럼틀 붙여 공 굴리기

**난이도 조절:** 어리면 크게·적게·느리게, 크면 작게·많게·규칙 추가 (색깔별로, 시간 안에, 팀 대결)

## 안전 원칙 (생활 물건은 장난감이 아니라서 더 중요해요)
- **3세 미만:** 휴지심 구멍(지름 약 3.5cm)에 들어가는 크기는 질식 위험이 있어요. 꼭 지켜보거나 빼 주세요.
- **비닐봉지·랩·고무줄·끈**은 얼굴이나 목에 닿지 않게 해요. 놀이가 끝나면 바로 치워요.
- **칼·가위·글루건**으로 하는 준비는 어른만 해요.
- **물놀이**는 얕은 물이라도 어른이 늘 옆에 있어요.
