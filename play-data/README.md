# 🎨 엄마표 놀이 데이터

공동육아 SOS · 독박육아 홈페이지에서 같이 쓸 **엄마표 놀이 모음**이에요.
원본은 `plays.json` 하나이고, `plays.csv`는 엑셀·구글 시트로 편하게 보고 고치기 위한 사본이에요.

## 쌓는 법
- **시트로:** `plays.csv`를 구글 시트에서 열어 줄을 추가하거나 고쳐요 → 다시 CSV로 내려받아 덮어써요 → `python3 build.py --from-csv`
- **바로:** `plays.json`에 항목을 추가해요 → `python3 build.py`
- `build.py`가 빠진 칸이나 잘못된 값을 검사하고, 나이순으로 정렬해서 두 파일을 같게 맞춰요.

## 칸 설명
| 칸 | 뜻 | 예 |
|---|---|---|
| id | 영어 짧은 이름 (겹치면 안 돼요). 후보는 `c-`로 시작 | `box-house` |
| status | 확정 (많이 알려진 놀이) · **후보** (원리로 새로 만든 놀이, 아직 안 해 봄) · 해봄 (직접 해 보고 다듬음) | 후보 |
| name | 놀이 이름 | 박스 놀이방 |
| ageMin · ageMax | 추천 나이 **개월** (0~96) | 9, 30 |
| place | 실내 · 실외 · 욕실 · 주방 | 실내 |
| group | 여럿이(공동육아 모임) 하기 좋은지 | O / X |
| minutes | 대략 걸리는 시간(분) | 20 |
| mess | 어지르는 정도 0 깔끔 · 1 보통 · 2 많이 | 2 |
| principles | 놀이 원리 ([principles.md](principles.md)의 14가지) | 당기고떼기 \| 꽂고잇기 |
| skills | 오감 · 소근육 · 대근육 · 언어 · 인지 · 사회성 · 창의 · 정서 | 오감 \| 소근육 |
| materials | 준비물 | 큰 택배 상자 \| 크레파스 |
| steps | 하는 방법 (순서대로) | 상자를 열어요 \| … |
| tip | 엄마 꿀팁 | |
| safety | 안전 메모 (특히 36개월 미만) | |
| keywords | 검색어 ("엄마표놀이 ○○"로 검색) | 박스놀이 \| 상자놀이 |
| swaps | 없으면 이걸로 (생활용품 대체 재료). 36개월 미만 놀이는 원래보다 작은 대체품을 쓰지 않아요 | 종이컵 → 밀폐용기 · 휴지 두루마리 |

CSV에서 여러 개는 ` | `로 나눠요.

## 후보 → 해봄
원리로 만든 **후보** 놀이는 아이와 직접 해 본 뒤 `status`를 **해봄**으로 바꿔요. 이때 걸린 시간, 팁, 안전 메모도 실제 경험대로 고쳐요. 사진은 해봄 놀이에만 찍어 붙여요.

## 지킬 것
- 블로그·SNS 글과 사진을 **그대로 옮기지 않아요.** 놀이 방법은 우리 말로 새로 써요. 사진은 직접 찍은 것만 써요.
- 3세 미만 놀이는 **작은 재료(질식 위험)**와 **입에 넣는 것**을 꼭 안전 메모에 적어요.
