# 🆘 공동육아 SOS 달력

급할 때 누가 아이를 봐줄 수 있는지 **달력에 체크만** 하는 공동육아 모임 도구예요.
대화는 오픈채팅·당근·밴드에서 하고, 이 앱은 날짜 체크만 맡아요.

- 방 만들기: 방 이름 + 비밀번호 → 초대 링크를 단톡방에 공유
- 들어가기: 링크 → 비밀번호 + 닉네임 (회원가입 없음)
- 날짜를 누르면 버튼 두 개: **🆘 도움 필요** / **✋ 나 이날 가능**
- 내가 올린 🆘은 "📣 단톡방에 알리기"로 알림 문구를 바로 공유

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 색과 모양 |
| `app.js` | 화면 동작 (방 만들기, 달력, 표시 올리기) |
| `store.js` | 저장소 (Firebase 또는 체험 모드) |
| `config.js` | Firebase 연결 설정값 (비어 있으면 체험 모드) |
| `firestore.rules` | 서버 보안 규칙 |
| `manifest.json`, `icon-*.png` | 휴대폰 설치용 정보와 아이콘 |

## 1. 실제 서버 연결하기 (처음 한 번, 약 10분)

`config.js`가 비어 있으면 **체험 모드**예요. 기록이 그 기기에만 저장돼서 다른 사람과 공유되지 않아요.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 **새 프로젝트** 만들기
   - 윤하 성장노트 프로젝트와 섞지 말고 따로 만드세요.
   - 요금제는 **Spark(무료)** 그대로 두세요. 카드 등록이 없어서 요금이 청구될 일이 없어요.
2. **Authentication → 로그인 방법 → 익명** 사용 설정
3. **Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - 프로덕션 모드로 시작
4. **Firestore → 규칙** 탭에 `firestore.rules` 내용을 그대로 붙여넣고 **게시**
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가(</>)** → 나오는 설정값을 `config.js`에 붙여넣기
6. GitHub에 올리면 GitHub Pages 주소에서 열려요.
   예: `https://kimddubuck.github.io/Yunha_education/sos/`

## 2. 베타 테스트용 APK 만들기

1. 위 1번을 끝내고 GitHub Pages 주소에서 앱이 열리는지 확인
2. [PWABuilder](https://www.pwabuilder.com)에 주소를 넣고 **Package for stores → Android** 선택
3. 내려받은 압축 파일 안의 `.apk`를 지인에게 전달
   - 받는 사람은 설치할 때 "출처를 알 수 없는 앱 허용"을 한 번 눌러야 해요.

> 사실 베타 테스트는 **링크만 보내도 충분해요.** 크롬에서 열고 메뉴 → "홈 화면에 추가"를 누르면 앱처럼 설치돼요.
> APK는 "진짜 앱 같은 느낌"을 확인하고 싶을 때 쓰세요.

## 비용

Firebase 무료(Spark) 한도: Firestore **읽기 하루 5만 건, 쓰기 하루 2만 건**.
방 하나를 한 번 열 때 그달 표시 수만큼 읽어요(보통 10~30건).
→ 하루 약 2,000번 열어도 무료예요. 무료 한도를 넘으면 요금이 나가는 게 아니라 그날 하루 멈춰요.

## 알아둘 점

- 비밀번호는 서버에 저장하지 않아요. "방 코드 + 비밀번호"로 만든 열쇠로만 방 위치를 찾아요.
  그래서 **비밀번호를 잊으면 방장도 되찾을 수 없어요.** (한 번 들어온 기기는 기억해요.)
- 휴대폰 브라우저 데이터를 지우면 "내가 올린 표시 지우기"가 안 될 수 있어요. (기기 번호가 바뀌기 때문)
- 아이 이름·사진 같은 개인정보는 받지 않아요. 닉네임과 날짜, 짧은 메모만 저장해요.
