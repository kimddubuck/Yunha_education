개인정보처리방침

오늘도 독박육아(이하 "사이트")는 회원가입이 없고, 이름·연락처 같은 개인정보를 받지 않아요.

저장하는 것

  • 내 브라우저에만: 마지막으로 고른 아기 개월수 (다음에 왔을 때 편하게 보이려고). 서버로 보내지 않아요.
  • 내 브라우저에만: 「👶 우리 아이 지금」에 적은 태어난 해·달·날, 성별, 키·몸무게. 계산도 휴대폰 안에서만 하고 서버로 보내지 않아요. 브라우저 기록을 지우면 같이 지워져요.

방문 통계 (Cloudflare Web Analytics)

사이트를 더 낫게 만들기 위해 Cloudflare Web Analytics로 방문 통계를 봐요. 이 도구는 쿠키를 쓰지 않고, 누가 왔는지 개인을 알아보지 않아요. 집계되는 것은 날짜별 방문·조회 수, 많이 본 페이지, 어디서 들어왔는지(검색·링크 등), 기기와 브라우저 종류, 나라·지역 단위의 대략적인 위치예요. IP 주소는 집계에만 잠깐 쓰이고 저장하지 않아요. 자세한 내용은 Cloudflare 안내를 봐 주세요.

방문 통계 (사이트 자체 집계)

어떤 글이 도움이 되는지 보려고 사이트가 직접 방문 수를 세요. 페이지를 열 때 날짜, 본 페이지 주소, 들어온 곳(네이버·구글처럼 사이트 이름만, 검색 주소에 들어 있으면 검색어), 기기 종류(휴대폰·태블릿·PC)만 서버(Cloudflare)에 남겨요. IP 주소, 쿠키, 이름 같은 개인을 알아볼 수 있는 정보는 저장하지 않아요. 다른 사이트로 가는 링크(공동육아 SOS 등)를 누르면 어느 사이트로 나갔는지도 세요. 같은 사람이 하루에 여러 번 세어지지 않도록 브라우저 저장소에 '오늘 방문함' 표시(날짜 한 줄)만 남겨요. 이 숫자는 운영자만 봐요.

🗺 육아 지도

「📍 내 위치」를 누르면 브라우저가 위치 허용을 물어봐요. 허용하면 내 위치는 이 휴대폰에서만 지도를 옮기는 데 쓰고, 서버에는 약 100m 단위로 반올림한 좌표만 보내요. 서버는 이 반올림한 좌표를 공공데이터포털(건강보험심사평가원·국립중앙의료원·행정안전부)에 전달해 주변 병원·약국·놀이시설을 찾고, 카카오 로컬 API에는 어느 시도인지 확인하는 데만 보내요. 위치는 어디에도 저장하지 않고, 같은 동네의 검색 결과만 잠깐 캐시해요.

쿠키와 광고 (Google 애드센스)

이 사이트는 Google 애드센스 광고를 실을 수 있어요. 광고를 실으면 이렇게 돼요.

  • Google을 포함한 제3자 광고 공급업체는 쿠키를 써서, 이용자가 이 사이트나 다른 사이트를 방문한 기록을 바탕으로 광고를 보여 줘요.
  • Google은 광고 쿠키를 써서 이 사이트와 인터넷의 다른 사이트 방문 기록을 바탕으로 광고를 게재할 수 있어요.
  • 맞춤 광고는 Google 광고 설정에서 끌 수 있어요. 다른 광고 공급업체의 맞춤 광고는 aboutads.info에서 끌 수 있어요.
  • Google이 정보를 어떻게 쓰는지는 Google 파트너 사이트 정보 이용 안내에서 볼 수 있어요.
