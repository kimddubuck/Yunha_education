방문 통계

방문자 수, 많이 본 페이지, 들어온 곳(유입 경로), 검색어를 봐요.

🔒 비밀번호

Cloudflare에 넣어 둔 ADMIN_KEY 값을 입력해요. 이 기기에만 기억해요.

⚙️ 처음 한 번만 설정해요

  1. Cloudflare 대시보드 → Storage & Databases → D1 → Create → 이름 dokbak-stats
  2. Workers & Pages → dokbak → Settings → Bindings → Add → D1 database → 변수 이름 STATS, 데이터베이스 dokbak-stats
  3. 같은 Settings → Variables and Secrets → Add → 종류 Secret, 이름 ADMIN_KEY, 값은 나만 아는 비밀번호
  4. Deployments → 맨 위 배포의 ⋯ → Retry deployment (설정이 적용돼요)
