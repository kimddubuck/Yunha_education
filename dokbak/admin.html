독박육아

🔒 운영자 비밀번호

Cloudflare에 넣어 둔 ADMIN_KEY를 입력해요. 이 기기에만 기억하고, 이 기기는 '내 방문'으로 따로 세요.

⚙️ 처음 한 번만 설정해요

  1. Cloudflare → Storage & Databases → D1 → Create → 이름 dokbak-stats
  2. Workers & Pages → dokbak → Settings → Bindings → Add → D1 database → 이름 STATS
  3. 같은 Settings → Variables and Secrets → Secret ADMIN_KEY = 나만 아는 비밀번호
  4. Deployments → 맨 위 배포 ⋯ → Retry deployment
