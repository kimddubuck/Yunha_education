# 구글 플레이스토어 등록 순서 (공동육아 SOS)

앱은 지금 웹앱(PWA)을 그대로 감싼 TWA 방식으로 올려요. 사이트를 고치면 앱에도 바로 반영돼요.

## 1. 개발자 계정 만들기 (운영자)
- https://play.google.com/console → 계정 유형 **개인** → 등록비 $25 (한 번)
- 신분증 인증, 연락처(ifb1321@gmail.com) 입력
- 개인 계정은 **비공개 테스트: 테스터 12명 × 14일**을 거쳐야 정식 출시 신청이 돼요

## 2. 앱 파일(AAB) 만들기 — PWABuilder (운영자, 10분)
1. https://www.pwabuilder.com 에 `https://gongdong-sos.pages.dev/index.html` 입력 → Start
2. **Package For Stores → Android → Generate Package**
   - Package ID: `dev.pages.gongdong_sos.twa` (한 번 정하면 못 바꿔요)
   - App name: 공동육아 SOS / Short name: 공동육아 SOS
   - Signing key: **Create new** (다운로드되는 zip 안의 signing.keystore 와 비밀번호를 **꼭 안전하게 보관**)
3. 받은 zip 안에서 `app-release-signed.aab` 와 `assetlinks.json` 을 확인

## 3. 사이트와 앱 연결 (개발 쪽)
- zip 안의 `assetlinks.json` 내용을 보내 주면 `sos/.well-known/assetlinks.json` 으로 올려요
- Play Console 의 **앱 서명 키 SHA-256 지문**도 assetlinks.json 에 함께 넣어야 해요
  (Play Console → 설정 → 앱 무결성 → 앱 서명 키 인증서)
- 연결이 안 되면 앱 위쪽에 주소창이 보여요

## 4. 스토어 등록 정보
- 앱 이름·설명: `플레이스토어_소개글.md`
- 앱 아이콘 512×512: `app_icon_512.png`
- 그래픽 이미지 1024×500: `feature_graphic_1024x500.png`
- 휴대전화 스크린샷(1080×1920): `screenshots/` 폴더 8장 (예시 데이터)
- 카테고리: 육아(Parenting) / 대상 연령: 18세 이상 / 광고: 없음
- 개인정보처리방침: https://gongdong-sos.pages.dev/safety.html
- 이용약관: https://gongdong-sos.pages.dev/terms.html
- 계정 삭제 안내 URL: https://gongdong-sos.pages.dev/safety.html#delete-me

## 5. 데이터 보안(Data safety) 답변
- 수집하는 데이터:
  - **기기 또는 기타 ID**: 익명 로그인 번호(uid), 알림 주소(FCM 토큰) — 앱 기능용, 공유 안 함
  - **사용자 생성 콘텐츠**(기타): 닉네임, 모임 글·댓글, SOS 요청 — 앱 기능용, 같은 방 사람만 봄
- 전송 중 암호화: 예 / 삭제 요청 방법: 앱 안 '내 정보 모두 지우기'
- 광고·분석 SDK: 없음

## 6. 테스트 → 출시
1. **비공개 테스트** 트랙에 AAB 업로드 → 테스터 12명 이메일 등록 → 14일
2. 테스트 끝나면 **프로덕션** 출시 신청 → 심사(보통 며칠)
