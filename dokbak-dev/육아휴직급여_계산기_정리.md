# 💰 육아휴직 급여 계산기 정리

> 독박육아.com `support/leave-pay-calc.html`에서 쓰는 계산 방식이에요. 다른 곳에서 쓸 수 있게 기준·공식·예시·코드를 모았어요.
> 실제 계산 코드: `dokbak-dev/leavepay.js`
> 정리한 날: 2026-10-23 · 기준은 2025년 이후 휴직(현행 제도)이에요. 쓰기 전에 아래 출처에서 바뀐 게 없는지 꼭 확인하세요.

---

## 1. 입력값

| 값 | 설명 |
|---|---|
| 통상임금 (월, 만 원) | 휴직 시작일 기준 월 통상임금 |
| 휴직 개월 수 | 일반·한부모 최대 12개월, 6+6은 최대 18개월(부모 각각 3개월 이상 쓸 때) |
| 휴직 시작일 (선택) | 넣으면 달마다 기간(예: 11/10~12/9)과 6+6 차액 들어오는 달을 계산 |
| 배우자 통상임금·개월·시작일 | 6+6일 때만 |

---

## 2. 기준표 (만 원)

**공통:** 받는 돈 = `min(통상임금 × 비율, 상한)`, 단 **하한 70만 원**보다 적으면 70만 원.

### 일반 육아휴직
| 개월째 | 비율 | 상한 |
|---|---|---|
| 1~3 | 100% | 250 |
| 4~6 | 100% | 200 |
| 7~ | 80% | 160 |

### 한부모
| 개월째 | 비율 | 상한 |
|---|---|---|
| 1~3 | 100% | **300** |
| 4~ | 일반과 같음 | |

### 6+6 부모육아휴직제 (부모 각각 첫 6개월)
| 개월째 | 1 | 2 | 3 | 4 | 5 | 6 | 7~ |
|---|---|---|---|---|---|---|---|
| 비율 | 100% | 100% | 100% | 100% | 100% | 100% | 일반과 같음 (80%, 160) |
| 상한 | 250 | 250 | 300 | 350 | 400 | 450 | |

---

## 3. 6+6 핵심 규칙 (가장 헷갈리는 부분)

1. **공통 개월에만 붙어요.**
   `공통 개월 = min(6, 내 개월 수, 배우자 개월 수)`
   - 예: 배우자가 3개월만 쓰면, 나도 3개월째까지만 6+6이에요. 4~6개월째는 일반 기준.
2. **먼저 쓴 사람은 일반 급여로 먼저 받아요.**
   - 내 k개월째 상향분은 **배우자도 k개월째를 다 써야** 붙어요.
   - 그래서 먼저 쓴 사람의 k개월째는 일반 금액으로 먼저 받고, **배우자의 k개월째가 끝나면 차액**(6+6 금액 − 먼저 받은 금액)을 받아요.
   - 차액은 한 번에 몰아서가 아니라 **달마다 따로** 들어와요.
3. **판단 방법 (코드 기준):** 내 k개월째 기간 끝날짜 < 배우자 k개월째 끝날짜 → 그달은 일반으로 먼저 받고, 차액은 `배우자 k개월째 끝난 다음 날`에 들어오는 것으로 계산.
   - 두 사람이 같은 날 시작하거나, 내가 나중에 시작하면 처음부터 6+6 금액.

> ⚠️ **불확실한 점:** 공식 자료에는 "나중에 쓰는 사람의 급여를 줄 때 먼저 쓴 사람의 차액을 준다"까지만 나와요. "배우자의 k개월째가 끝난 달에 k개월째 차액"이라는 시점은 실제 수령 경험을 참고한 해석이에요. **합계 금액은 같지만 들어오는 달은 다를 수 있어요.** 고용24 지급 내역이나 고용센터(☎ 1350)에서 확인하라고 꼭 안내하세요.

**기타**
- 실제 입금은 그달이 끝나고 신청한 뒤라 **한 달쯤 늦어요.**
- 표의 '달'은 그달에 시작하는 'k개월째' 급여 기준이에요.

---

## 4. 날짜 계산

- k개월째 기간 = `시작일 + (k−1)개월` ~ `시작일 + k개월 − 1일`
- 말일 보정: 1/31 시작 → 2개월째는 2/28(윤년 2/29)부터. 그 달 마지막 날보다 큰 날짜는 마지막 날로 맞춰요.
- 예: 11/10 시작 → 1개월째 11/10~12/9, 2개월째 12/10~1/9

---

## 5. 계산 예시 (통상임금 400만 원)

### 일반 12개월
| 개월째 | 계산 | 받는 돈 |
|---|---|---|
| 1~3 | 400 → 상한 250 | 250 × 3 = 750 |
| 4~6 | 400 → 상한 200 | 200 × 3 = 600 |
| 7~12 | 400 × 80% = 320 → 상한 160 | 160 × 6 = 960 |
| **합계** | | **2,310만 원** |

### 6+6, 부부 둘 다 400만·6개월, 같은 날 시작
| 개월째 | 1 | 2 | 3 | 4 | 5 | 6 | 합계 |
|---|---|---|---|---|---|---|---|
| 한 사람 | 250 | 250 | 300 | 350 | 400 | 400 | **1,950** |

(6개월째 상한은 450이지만 통상임금 400이 더 작아서 400)
부부 합계 3,900만 원.

### 6+6, 엄마 7/1 시작 · 아빠 10/1 시작 (둘 다 400만·6개월)
엄마가 먼저 썼으니 일반 금액으로 먼저 받고, 아빠의 k개월째가 끝날 때 차액을 받아요.

| 엄마 개월째 | 먼저 받음 (일반) | 6+6 금액 | 차액 | 차액 들어오는 때 (아빠 k개월째 끝난 뒤) |
|---|---|---|---|---|
| 1 (7월) | 250 | 250 | 0 | – |
| 2 (8월) | 250 | 250 | 0 | – |
| 3 (9월) | 250 | 300 | **50** | 아빠 3개월째(12/1~12/31) 끝난 뒤 → 1월 |
| 4 (10월) | 200 | 350 | **150** | 아빠 4개월째 끝난 뒤 → 2월 |
| 5 (11월) | 200 | 400 | **200** | → 3월 |
| 6 (12월) | 200 | 400 | **200** | → 4월 |
| **합계** | 1,350 | | **600** | 1,350 + 600 = **1,950** |

아빠는 나중에 썼으니 처음부터 6+6 금액(250·250·300·350·400·400 = 1,950)을 받아요.

## 6. 이식용 핵심 코드 (JavaScript, 화면 없이 계산만)

```js
// 단위: 만 원 · mode: 'g' 일반, 'h' 한부모, 's' 6+6
const CAP66 = [250, 250, 300, 350, 400, 450], FLOOR = 70;

function rule(k, mode){                       // k: 몇 개월째 (1부터)
  if(mode === 's' && k <= 6) return {rate: 100, cap: CAP66[k - 1]};
  if(k <= 3) return {rate: 100, cap: mode === 'h' ? 300 : 250};
  if(k <= 6) return {rate: 100, cap: 200};
  return {rate: 80, cap: 160};
}
function pay(k, wage, mode){
  const r = rule(k, mode);
  return Math.max(Math.min(wage * r.rate / 100, r.cap), FLOOR);
}

// 날짜: start + n개월 (말일 보정)
function addMonths(d, n){
  const x = new Date(d.getFullYear(), d.getMonth() + n, 1);
  const last = new Date(x.getFullYear(), x.getMonth() + 1, 0).getDate();
  x.setDate(Math.min(d.getDate(), last)); return x;
}
function monthSpan(start, k){                 // k개월째 {from, to}
  const from = addMonths(start, k - 1);
  const to = new Date(addMonths(start, k).getTime() - 864e5);
  return {from, to};
}

// 한 사람 계산. other = {start, months} (6+6일 때 배우자)
function leavePay(wage, months, mode, start, other){
  const common = mode === 's' ? Math.min(6, months, other ? other.months : 6) : 0;
  const rows = []; let total = 0;
  for(let k = 1; k <= months; k++){
    let m = mode, settle = null;
    if(mode === 's' && k <= 6){
      if(k > common) m = 'g';                                  // 공통 개월 밖 → 일반
      else if(start && other && other.start){
        const mine = monthSpan(start, k), theirs = monthSpan(other.start, k);
        if(theirs.to > mine.to) m = 'g', settle = new Date(theirs.to.getTime() + 864e5);   // 먼저 씀 → 일반 먼저, 차액은 나중에
      }
    }
    const first = pay(k, wage, m);
    const diff = settle ? pay(k, wage, 's') - first : 0;
    rows.push({k, first, diff, settleAt: settle});
    total += first + diff;
  }
  return {total, rows, common};
}

// 예) leavePay(400, 6, 's', new Date(2026,6,1), {start: new Date(2026,9,1), months: 6}).total → 1950
```

## 7. 화면에서 같이 보여 주는 것 (참고)

- 일반 급여만 썼을 때와 6+6 비교: "6+6으로 나는 ○○원 더 받아요"
- 공통 개월이 6보다 적으면: "6+6 상향은 두 사람이 공통으로 쓴 ○개월에만 붙어요"
- 12개월 넘게 고르면: "12개월이 넘는 휴직(최대 1년 6개월)은 부모가 각각 3개월 이상 쓸 때 가능해요"
- 부부 한눈에 표: 달력 달마다 나 · 배우자 · 합계, 6+6이 붙는 달은 색 띠, 차액은 "+50만 300−250"처럼 뺄셈 표시
- 금액은 표에서는 만 원 단위(좁은 화면 320px 대비), 요약은 원 단위
- 입력값은 휴대폰(localStorage)에만 저장, 서버로 안 보냄
