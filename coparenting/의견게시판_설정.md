# 공동육아 사이트 · 의견 게시판 설정 (처음 한 번만)

사이트: `coparenting/index.html` (놀이 목록은 `coparenting/plays.js`)
주소: GitHub Pages가 main 브랜치를 쓰면 https://kimddubuck.github.io/Yunha_education/coparenting/

## 의견이 저장되는 곳
- 성장노트와 같은 Firebase 프로젝트(yunhaeducation)의 Firestore, `coparenting_opinions` 컬렉션
- 저장하는 것: 주제(habit/dev), 의견 글(500자까지), 고른 놀이 이름, 저장 시각. 이름·로그인 정보는 저장하지 않음
- 누구나 읽을 수 있음 (사이트가 공개라서). 페이지에 "아이 이름은 적지 말아 주세요" 안내가 있음

## 1단계: Firestore 보안 규칙에 한 덩어리 추가
Firebase 콘솔 → Firestore Database → 규칙(Rules) 탭.
기존 규칙은 지우지 말고, `match /databases/{database}/documents {` 바로 아래 줄에 아래를 붙여 넣고 [게시]를 누르기.

```
    // 공동육아 사이트 익명 의견 (로그인 없이 쓰기·읽기, 수정 불가, 삭제는 로그인한 사람만)
    match /coparenting_opinions/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['topic', 'text', 'play', 'createdAt'])
        && request.resource.data.topic in ['habit', 'dev']
        && request.resource.data.text is string
        && request.resource.data.text.size() > 0
        && request.resource.data.text.size() <= 500
        && (!('play' in request.resource.data)
            || (request.resource.data.play is string && request.resource.data.play.size() <= 40))
        && request.resource.data.createdAt == request.time;
      allow update: if false;
      allow delete: if request.auth != null;
    }
```

## 2단계: 사이트 주소 열기
