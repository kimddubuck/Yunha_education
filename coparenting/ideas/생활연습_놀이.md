# 생활 연습 놀이 목록

먹기·입기·버리기·정리를 놀이로 연습하는 활동. 사용자가 제안함 (2026-10-02)
규칙: 음식 없이(빈 그릇·빈 컵), 작은 물건 X, 새로 사지 않기

| 놀이 | 하는 방법 | 쓰는 물건 | 사용 회차 |
|---|---|---|---|
| 숟가락으로 옮기기 | 큰 숟가락·국자로 양말 공을 그릇에서 그릇으로 | 큰 숟가락, 국자, 그릇 2개, 양말 | |
| 기저귀 쓰레기통에 쏙 | 새 기저귀를 돌돌 말아 뚜껑 있는 통에 버리기. "버려 줘서 고마워!" | 새 기저귀, 뚜껑 있는 빈 통 | |
| 신발 벗어 신발장에 | 실내화를 벗어 상자 신발장에 넣기 | 실내화, 택배 상자 | |
| 소매에 팔 넣기 | 엄마 아빠의 헐렁한 티셔츠 소매에 팔 넣어 보기 | 헐렁한 티셔츠 | |
| 손수건으로 닦기 | 손수건으로 바닥·인형 얼굴 닦는 흉내 | 손수건, 인형 | |
| 빈 컵으로 마시는 척 | 빈 컵으로 "꿀꺽", 인형에게도 먹여 주기 | 빈 플라스틱 컵, 인형 | |
| 인형 재우기 | 손수건 이불 덮고 토닥토닥 — ex) 자장가 | 인형, 손수건 | |
| 뚜껑 열고 닫기 | 큰 반찬통 뚜껑 열고 닫고, 손수건 넣었다 빼기 | 큰 반찬통, 손수건 | |
