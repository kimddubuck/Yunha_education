# ① 우리 일 함께하기 (상황극) 목록

엄마 아빠가 하는 일에 아이를 "~해 볼래?" 하고 참여시키는 상황극. 사용자가 제안함 (2026-10-02)
- 하나 정해서 몇 주 계속 반복 (발달 놀이는 자주 새로)
- 먹는 음식 X (통야채는 씻기만 하고 집에 가져감), 작은 물건 X
- 물은 대야·컵에 조금만, 바닥에 수건 깔기

| 놀이 | 건네는 말 | 하는 방법 | 쓰는 물건 | 사용 회차 |
|---|---|---|---|---|
| 숟가락질 | 숟가락 해 볼래? | 큰 숟가락·국자로 양말 공을 그릇에서 그릇으로 | 큰 숟가락, 국자, 그릇 2개, 양말 | |
| 쓰레기통에 버리기 | 이거 버려 줄래? | 새 기저귀를 돌돌 말아 뚜껑 있는 통에 | 새 기저귀, 뚜껑 있는 빈 통 | |
| 바구니에 넣기 | 이거 넣어 줄래? | 양말·손수건을 건네며 바구니에 넣어 달라고 부탁 | 양말, 손수건, 빨래 바구니 | |
| 빨래 개기 | 빨래 이거 개 줄래? | 수건 반 접기 시늉, 짝 양말 찾기, 바구니에 담기 | 수건, 손수건, 양말, 빨래 바구니 | |
| 컵으로 물 마시기 | 빨대 없이 마셔 볼래? | 작은 컵에 물 한 모금, 두 손으로 잡고 마시기 | 작은 컵, 물병, 수건 | |
| 쓱싹쓱싹 닦기 | 쓱싹쓱싹 닦아 볼래? | 젖은 손수건으로 탁자·바닥·인형 닦기 | 손수건, 분무기, 인형 | |
| 야채 씻기 | 야채 씻어 볼래? | 대야 물에 통감자·당근 문질러 씻기. 먹지 않음 | 대야, 통감자·당근, 수건 | |
| 손 씻기 | 손 씻어 볼래? | 대야 물에 손 담그고 비비기, 수건으로 닦기 — ex) 손을 씻어요 | 대야, 수건 | |
| 신발 정리 | 신발 넣어 줄래? | 실내화 벗어 상자 신발장에 | 실내화, 택배 상자 | |
| 옷 입기 | 팔 쏙 넣어 볼래? | 헐렁한 티셔츠 소매에 팔 넣기 | 헐렁한 티셔츠 | |
| 인형 재우기 | 아기 재워 줄래? | 손수건 이불 덮고 토닥토닥 — ex) 자장가 | 인형, 손수건 | |

# ② 발달 놀이 중 새로 추가한 감각 놀이

| 놀이 | 하는 방법 | 쓰는 물건 | 사용 회차 |
|---|---|---|---|
| 얼음 만져 보기 | 대야에 큰 얼음덩어리(컵에 얼린 것)를 넣고 만지고 밀기. 작은 조각은 치우기 | 대야, 큰 얼음, 수건 | |
| 얼음 지퍼백 주무르기 | 얼음과 물을 지퍼백에 넣고 꽉 잠가 눌러 보기 | 지퍼백, 얼음, 수건 | |
| 여러 촉감 만져 보기 | 수건, 비닐봉지, 냄비 뚜껑, 털 인형 차례로 만지기 | 수건, 비닐봉지, 냄비 뚜껑, 인형 | |

## 재료가 겹치는 짝 예시
- 손 씻기 + 얼음 만져 보기 → 대야, 수건
- 빨래 개기 + 팝콘 놀이 → 양말, 이불·수건
- 신발 정리 + 장애물 코스 → 택배 상자
