## ⚠️ 검증 수준: 원문 미확인
- 수집 환경에서 네트워크가 막혀 아래 사이트를 **하나도 직접 열지 못함**. 모두 검색 결과의 요약 문장을 보고 정리함
- 활동 이름은 원문 그대로가 아닐 수 있음. "집 생활용품으로 바꾸면" 칸은 정리하면서 적은 것
- 지어낸 활동은 없음. 원문을 확인하면 "확인" 칸에 ✅ 표시

## 응용하지 않은 것 (이유)
- 씨앗·나뭇가지·돌멩이, 집게, 구슬 물병, 쌀·콩·단추 소리통 → 삼킬 수 있는 작은 물건
- 물 스펀지, 비눗방울, 분필 트랙 → 물·정리 부담, 실외
- 간식 봉지 넣기, 요리 놀이 → 음식 활동
- 상자 꾸미기(크레용·색지), 두 상자 테이프 터널 → 꾸미기·테이프
- 편백 큐브, 비치볼 → 사야 하는 물건 (비치볼은 집에 있으면 가능)
- 그림자 놀이 → 손전등, 공용 공간을 어둡게 해야 함
- 양말 인형(단추 꿰매기), 스타킹 애벌레 → 만들기 위주, 12~16개월에 이름
- Vroom → 구체적인 1세 팁을 검색으로 확인하지 못해 넣지 않음
