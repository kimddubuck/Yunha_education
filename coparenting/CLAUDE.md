# 아파트 오전반 공동육아 — 작업 규칙

## 개요
- 아파트 커뮤니티 실내에서 하는 오전반 공동육아 놀이 기록·공지 자료 저장소
- 대상: 2025년 6~10월생 아이들 (2026년 10월 기준 12~16개월)
- 매 회차 단톡방에 올릴 A4 1장 공지 이미지(PNG)와 PDF를 만든다

## 폴더
- `sessions/` — 회차별 기록 (YYYY-MM-DD_주제.md). 계획, 실제 반응, 다음에 바꿀 점
- `research/` — 확인한 연구 근거 메모 (공지에는 넣지 않음, 질문받을 때 참고용)
- `templates/` — 공지 HTML 템플릿, render.py 변환기
- `output/` — 완성된 공지 PNG/PDF
- `index.html` + `plays.js` — 공개 놀이 고르기 사이트(GitHub Pages)와 익명 의견 게시판. 놀이 추가·`used` 회차 기록은 plays.js만 고치기. 설정은 `의견게시판_설정.md`
- `ideas/어린이집_응용_목록.md` — 어린이집 활동을 집 생활용품으로 바꾼 목록. 새 회차는 여기서 고르고, 쓴 회차를 표시
- `ideas/외부자료_응용_목록.md`, `ideas/생활연습_놀이.md` — 공공·해외 자료(원문 미확인), 생활 연습 놀이 목록

## 개인정보
- 이 저장소는 공개(public). 어린이집 이름·반 이름, 계획안 원본 사진, 아이 이름은 올리지 않기
- 의견 게시판 글은 Firestore에 저장되고 누구나 읽을 수 있음. 이름·로그인 정보는 저장하지 않음

## 공지 작성 규칙 (사용자가 직접 정한 것)
- 디자인: 노션 스타일, Pretendard 글꼴, 흰 바탕 + 차콜 글씨, 연회색 태그. 알록달록한 색 지양
- A4 한 장 안에 모두 담기. render.py로 넘침 확인
- 글자가 어색하게 줄바꿈되지 않게 다듬기 (예: 마지막 줄에 한 단어만 남지 않게)
- 맨 위: 날짜(YYYY. MM. DD. 요일 오전), 모임명, 준비물 속성 줄
- 준비물은 "없어도 괜찮아요" — 필수로 쓰지 않기. 사용자가 기본 물품을 챙겨 감
- 놀이는 어린이집 월간계획안 활동을 응용 — 아이들이 익숙한 놀이를 집 생활용품으로 바꿔서. 공지 놀이 칸에 🏫 표시로 원래 어린이집 활동명을 함께 적기(어린이집 이름은 쓰지 않음)
- 회차 구성: 놀이는 2개 + 마무리 정리
  1. 우리 일 함께하기 (ideas/생활연습_놀이.md) — "숟가락 해 볼래?", "빨래 개 줄래?"처럼 어른 일에 참여하는 상황극. 하나 정해서 몇 주 계속 반복. 처음에 반응이 적어도 바로 바꾸지 않기
  2. 발달 놀이 — 터널, 얼음 만지기처럼 자주 새로운 경험으로 바꾸기 (안 해 본 것 우선)
  - 두 놀이는 재료가 겹치게 골라 준비를 쉽게 (예: 숟가락으로 옮기기 + 팝콘 놀이 → 양말 공을 같이 씀)
- 놀잇감은 새로 사지 않기 — 집에 있는 생활용품(상자, 양말, 손수건, 바구니, 냄비 등)으로만 간단하게
- 삼킬 수 있는 작은 물건(병뚜껑 등)은 쓰지 않기
- 시간표·순서·소요시간 쓰지 않기 — 편할 때 오고 가는 자유 참여
- 노래는 모두 `ex)` 표시 — 참고용 예시일 뿐 강제가 아님
- 이모지 📅 쓰지 않기 (그림 속에 다른 날짜가 찍혀 있음) → 📌 사용
- 넣지 않는 것:
  - 연구 출처·논문 이름 (반박 심리 유발 우려). 효과 설명은 근거 있는 내용만 쓰되 출처는 생략
  - "혼자보다 함께 키우면 좋은 점" 같은 비교 (못 오는 사람이 소외감 느낄 수 있음)
  - 이름 인사 노래 등 부모가 부끄러워할 수 있는 활동
  - 특정 아이 이름
  - 먹는 음식 활동(치우기 번거로움), 벽·바닥에 붙이는 활동(공용 시설). 단, 통야채 씻기·컵으로 물 마시기·손 씻기는 OK — 물은 대야·컵에 조금만, 수건 깔기
  - 만들기 방법·안전 약속 긴 설명 (굳이 필요 없음)
- 효과 설명은 지어내지 말 것. research/에 확인된 내용만 사용하고, 과장 없이 "연결됐어요/관련됐어요"로 표현

## 사용자 장비
- 우쿨렐레: '곰 세 마리' 연주 가능
- 블루투스 스피커로 노래 재생
- 냄비 등 놀잇감 직접 챙겨 감
